# ตัวอย่างรูปสำหรับเดโม Auto Punch

รูป flat-color วาดเอง (CC0 — ใช้ในแอปเชิงพาณิชย์ได้) ออกแบบให้ trace เป็นลายปักได้สวย:
สีเรียบ ขอบชัด จำนวนสีจำกัด (ภาพถ่าย/ไล่เฉดจะออกมาไม่ดี)

วิธีใช้: เมนูวงกลม (ปุ่ม + มุมขวาล่าง) → "สร้าง" → "แกะลายจากรูป (Auto Punch)"
แล้วเลือกไฟล์ หรือลากรูปมาวางบนแอปได้เลย

| ไฟล์ | ภาพ | จำนวนสีแนะนำ | ใช้เดโมอะไร |
|---|---|---|---|
| `fox.png` | จิ้งจอก | 5 | เคสทั่วไป — ปิดเลเยอร์สีขาวเพื่อไม่ปักพื้น |
| `flower.png` | ดอกไม้ (พื้นโปร่งใส) | 4 | พื้นหลังโปร่งใสถูกตัดออกอัตโนมัติ |
| `coffee.png` | แก้วกาแฟ | 6 | เคสทั่วไป หลายรูปทรง |
| `mountains.png` | ภูเขา | 6–8 | หลายสี + ลองโหมดซ้อนชั้น |
| `parrot.png` | นกแก้ว | 7 | หลายสีสด |
| `ring-heart.png` | วงแหวน+หัวใจ (มีรู, พื้นโปร่งใส) | 2 | ทดสอบว่ารู (hole) ไม่ถูกปักทับ |

เคล็ดลับ:
- **ปิดเลเยอร์สีพื้น** (เช่น สีขาวของ fox/coffee) ในรายการสี ถ้าต้องการปักเฉพาะตัวลาย
- **ลบจุดเล็ก (มม.²)** เพิ่มขึ้นถ้ามีจุดสีเล็กๆ ที่ไม่ต้องการ
- ติ๊ก **"ใส่รูปต้นฉบับเป็น Background"** เพื่อวางรูปอ้างอิงใต้ลายไว้เทียบ

รูปเหล่านี้สร้างด้วย `scripts/` เดโม (ไม่ผูกกับ build) — ย้าย/ลบได้ตามสะดวก
